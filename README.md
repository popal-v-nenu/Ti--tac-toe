# Крестики-нолики (Tic-Tac-Toe)

Классическая игра «Крестики-нолики» с графическим интерфейсом на **Windows Forms**. 
Проект демонстрирует применение объектно-ориентированного подхода, событийно-ориентированного программирования и реализацию AI противников разного уровня сложности.

### Основной функционал:
- 🎮 4 режима игры: [два_игрока](#два_игрока) / [легкий бот](#легкий_бот) / [средний бот](#средний_бот) / [невозможный бот](#невозможный_бот)
- 🎨 Смена темы оформления: черная и белая тема
- 🤖 Три уровня сложности бота (включая "непобедимого")
- 🏆 Определение победных комбинаций и ничьей
- 🔄 Перезапуск игры без закрытия приложения
- 📐 Адаптивный интерфейс с изменяемым размером окна

## два_игрока
Режим где 2 человека играют друг против друга на одном устройстве

## легкий_бот
Бот совершает полностью случайные ходы

## средний_бот
Бот сначала проверяет все поле на возможность победить, затем проверяет на возможность защититься, иначе ставит полностью случайные ходы

## невозможный_бот
Бот свой первый ход ставит на рандомные нечетные клетки, затем проверяет паттерны победы, почти не делает случайные ходы

# Крестики-нолики (Tic-Tac-Toe)

Классическая игра «Крестики-нолики» с графическим интерфейсом на **Windows Forms**. Проект демонстрирует применение объектно-ориентированного подхода, событийно-ориентированного программирования и реализацию AI противников разного уровня сложности.

### Основной функционал:
- 🎮 4 режима игры: два игрока / легкий бот / средний бот / невозможный бот
- 🎨 Смена темы оформления: черная и белая тема
- 🤖 Три уровня сложности бота (включая "непобедимого")
- 🏆 Определение победных комбинаций и ничьей
- 🔄 Перезапуск игры без закрытия приложения
- 📐 Адаптивный интерфейс с изменяемым размером окна

## 🛠 Технологии

| Технология | Версия |
|------------|--------|
| **Язык программирования** | C# |
| **.NET** | 9.0 |
| **Фреймворк GUI** | Windows Forms |
| **Тестирование** | NUnit (юнит-тесты) |

## 🧪 Тестирование

Для проверки корректности работы ключевых алгоритмов написаны юнит-тесты. Тесты покрывают основной класс игровой логики `Field.cs`.

### Протестированные методы:
- ✅ Проверка победных комбинаций (крестики / нолики)
- ✅ Определение ничьей при заполненном поле
- ✅ Проверка доступности ходов
- ✅ Корректность сброса игрового поля
